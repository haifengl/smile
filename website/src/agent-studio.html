Agent Studio

Explore it, one seat at a time.

SMILE Studio is the agentic desktop IDE for data science. Free to evaluate. Annual seats cover production use.

Start Read the license

What you work in

A notebook, an agent panel, and the project sit in one window on your machine. A fitted model leaves as a file you can serve.

Notebook

Java, Scala, and Python cells in one editor. A prompt field and Tab completion write code into the cell.

Agents

Seven agents, each in its own tab, for analysis, Java, Python, product, architecture, coordination, and the desktop.

AutoML

Clair takes a data file through profiling, features, model selection, tuning, and evaluation. /automl runs that path end to end.

Export

Double-click a model in the kernel explorer to save a .sml file, or start a REST inference service for it.
