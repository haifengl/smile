Agent Studio

Hand it the data, the code, or the company.

Agent Studio is a coding agent on your machine, an AutoML workplace that builds the models for Serve Engine, and an operating system for startups. SMILE 7 was built here. HALO.AI runs in it. Free to evaluate. Annual seats cover production use.

What you work with

Agents

Seven agents run a company from the idea to delivery. More are on the way. They are your coworkers, so the customer problem stays yours.

AutoML

Clair drives the end to end AutoML process from exploration, features, model selection, tuning, to evaluation.

Handoff

A fitted model leaves as a .sml file and exports as an ONNX graph for Serve Engine. Run the model in your applications or in our Serve Engine on the edge.

Notebook

Java, Kotlin, Scala, and Python notebooks, where you audit the generated AutoML pipelines. Tab completion is there when you want to code.

A workplace that builds the model

The coding work covers the project, the edits, the commands, and the tests, in the same class as Claude Code. Clair explores the data and builds the model, which can be hot-loaded into Serve Engine from Studio. SMILE 7.0.0, including Studio itself, was built in this workplace.

Your provider and your language

OpenAI, Anthropic, Google Gemini, Azure OpenAI, Vertex AI, or an OpenAI-compatible endpoint for an open-weight model. The key stays on your machine.

Notebooks and AutoML run in Java, Kotlin, Scala, and Python. When you prefer to write the code, the notebook is that path.
