Anomaly Detection

Overview

The package smile.anomaly provides two main approaches for unsupervised and semi-supervised anomaly detection:

Isolation Forest (IsolationForest) — a tree-ensemble, unsupervised anomaly scorer for numeric tabular data.

One-Class SVM (SVM<T>) — kernel-based novelty detection that learns the support of a high-dimensional distribution.

ClassAlgorithmScore direction
IsolationForestRandom-partition tree ensembleHigher → more anomalous
SVM<T>One-class support vector machineLower (negative) → more anomalous

Both classes are Serializable and support round-trip persistence via smile.io.Write.object / smile.io.Read.object.

Algorithm Selection Guide

Use Isolation Forest when the data is numeric tabular (double[][]), you need a fast scalable unsupervised baseline, you want intuitive scores in (0, 1] where values above roughly 0.5 flag anomalies, or you want to experiment with extended hyperplanes via extensionLevel.

Use One-Class SVM when you need flexible non-linear normality boundaries via custom kernels, the training data is uncontaminated (no outliers — the SVM learns a tight hypersphere around it), and the data size is moderate (kernel methods scale as O(n²) in memory and time).

Isolation Forest

Class: smile.anomaly.IsolationForest. Isolation Forest recursively partitions samples with random splits; anomalies tend to be isolated in fewer partitions and therefore receive shorter average path lengths (higher anomaly scores). Extended Isolation Forest replaces axis-aligned splits with random-slope hyperplanes controlled by extensionLevel.

Quick Start

{% include "components/playground-extra-actions.njk" %} 
import smile.anomaly.IsolationForest;

double[][] train = {
    {0.0, 0.0}, {0.1, -0.1}, {-0.05, 0.05},
    {0.05, 0.08}, {-0.08, -0.03}
};

// Fit with default options (100 trees, extensionLevel=0)
IsolationForest model = IsolationForest.fit(train);

// Score individual points — higher means more anomalous

double outlierScore = model.score(new double[] { 6.0,  -6.0});

System.out.printf("inlier  score = %.4f%n", inlierScore);
System.out.printf("outlier score = %.4f%n", outlierScore);

Options

Hyperparameters are fields of the nested IsolationForest.Options record. Pass an Options instance to fit, or a java.util.Properties map using the keys below (Options.toProperties() / Options.of(props) round-trip).

ntrees
smile.isolation_forest.trees
Number of isolation trees (default 100; must be ≥ 1).
maxDepth
smile.isolation_forest.max_depth
Maximum tree depth. 0 (default) means auto — log₂ of the subsample size.
subsample
smile.isolation_forest.sampling_rate
Fraction of rows used to train each tree (default 0.7; must be in (0, 1)).
extensionLevel
smile.isolation_forest.extension_level
How many feature dimensions participate in the random splitting hyperplane (default 0 = standard Isolation Forest). Valid range [0, p−1].

Extension Level Semantics

The extensionLevel controls how many feature dimensions participate in the random splitting hyperplane:

extensionLevelBehaviour
0Standard Isolation Forest — axis-aligned splits
1 … p−2Intermediate — hyperplanes in an (extensionLevel+1)-dimensional subspace
p−1Fully extended — hyperplanes with random slopes in all dimensions

Valid range is [0, p−1], where p is input dimensionality. Setting extensionLevel ≥ p raises IllegalArgumentException. Read the fitted level back with model.extensionLevel().

{% include "components/playground-extra-actions.njk" %} 
import smile.anomaly.IsolationForest;

double[][] data = { /* p = 2 */ };
// Standard Isolation Forest (extensionLevel = 0)
var std = IsolationForest.fit(data, new IsolationForest.Options(100, 0, 0.7, 0));
System.out.println(std.extensionLevel()); // 0

// Extended Isolation Forest
var ext = IsolationForest.fit(data, new IsolationForest.Options(100, 0, 0.7, 1));
System.out.println(ext.extensionLevel()); // 1

Batch Scoring and Prediction

// Batch score — runs in parallel
double[] scores = model.score(batchData);

// One-step predict: true → anomaly

predict(double[] x, double threshold) returns true when score(x) > threshold. Typical thresholds are in (0.5, 0.8) depending on the expected contamination rate.

One-Class SVM

Class: smile.anomaly.SVM<T> (extends smile.model.svm.KernelMachine<T>). One-class SVM identifies a hypersphere that encloses the training distribution. It is sensitive to outliers — prefer clean training data for novelty detection.

Quick Start

{% include "components/playground-extra-actions.njk" %} 
import smile.anomaly.SVM;
import smile.math.kernel.GaussianKernel;

double[][] train = {
    {0.0, 0.0}, {0.1, -0.1}, {-0.05, 0.05},
    {0.05, 0.08}, {-0.08, -0.03}
};

SVM<double[]> model = SVM.fit(
    train,
    new GaussianKernel(1.0),
    new SVM.Options(0.2, 1E-3)
);

// Positive → inlier, Negative → anomaly
double inlierScore  = model.score(new double[] { 0.02,  0.01});
double outlierScore = model.score(new double[] { 4.0,  -4.0});

System.out.printf("inlier  score = %.4f%n", inlierScore);
System.out.printf("outlier score = %.4f%n", outlierScore);

inlier  score ≈ 0.45
outlier score ≈ −0.72

Score convention: Unlike IsolationForest, SVM.score() returns the raw decision function value: positive = inlier, negative = anomaly. Any smile.math.kernel.MercerKernel<T> is accepted — commonly GaussianKernel(sigma), optionally PolynomialKernel or LinearKernel.

Options

Hyperparameters are fields of the nested SVM.Options record. Pass an Options instance to fit, or a java.util.Properties map using the keys below (Options.toProperties() / Options.of(props) round-trip). Fit with SVM.fit(x, kernel) or SVM.fit(x, kernel, options).

nu
smile.svm.nu
Upper bound on outlier fraction and lower bound on support-vector fraction. Range (0, 1]; default 0.5.
tol
smile.svm.tolerance
Solver convergence tolerance (must be > 0; default 1E-3).
Java {% include "components/playground-extra-actions.njk" %} 
import smile.anomaly.SVM;
import java.util.Properties;

var opts = new SVM.Options(0.1, 1E-4); // 10% contamination budget
Properties props = opts.toProperties();
SVM.Options loaded = SVM.Options.of(props);
assert opts.equals(loaded);

Data-Driven Threshold

When no labelled data is available, select a threshold from training scores using the expected contamination rate:

{% include "components/playground-extra-actions.njk" %} 
import smile.anomaly.IsolationForest;
import java.util.Arrays;

// IsolationForest — top `contamination` fraction flagged
double[] scores = model.score(train);
Arrays.sort(scores);
double contamination = 0.05; // 5% outliers
int idx = (int) ((1.0 - contamination) * (scores.length - 1));
double threshold = scores[idx];

boolean flag = model.predict(xNew, threshold);

Unsupervised Threshold Selection

{% include "components/playground-extra-actions.njk" %} 
import smile.anomaly.IsolationForest;
import java.util.Arrays;

double[][] data = loadData();
IsolationForest model = IsolationForest.fit(data);

double[] trainScores = model.score(data);
Arrays.sort(trainScores);

double contamination = 0.02; // 2% expected anomalies
int cutIdx = (int) ((1.0 - contamination) * (trainScores.length - 1));
double threshold = trainScores[cutIdx];

double[][] newBatch = loadNewData();
for (double[] x : newBatch) {
    if (model.predict(x, threshold)) {
        System.out.println("ANOMALY detected: " + Arrays.toString(x));
    }
}
