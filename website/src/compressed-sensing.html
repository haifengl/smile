Compressed Sensing

Compressed sensing recovers a high-dimensional signal from far fewer linear measurements than the Nyquist–Shannon rate when the signal is sparse (or sparse in a known basis). SMILE’s smile.cs package provides sensing matrices and three recovery algorithms:

  • MeasurementMatrix — Gaussian, Bernoulli, or partial-identity Φ, optional wavelet Ψ
  • OMP — Orthogonal Matching Pursuit (fast greedy, known k)
  • CoSaMP — Compressive Sampling Matching Pursuit (near-optimal greedy)
  • BasisPursuit — L1 minimization / BPDN (convex, k optional)

With a k-sparse x ∈ ℝⁿ and measurements y = A x where A ∈ ℝm×n and m ≪ n, recovery is typically reliable when m = O(k log(n/k)) (a practical rule of thumb is m ≥ 4k–5k).

Quick Start

Build a sparse ground truth, take Gaussian measurements, and recover with OMP and CoSaMP. Relative L2 error is machine-epsilon on this noiseless instance.

{% include "components/playground-extra-actions.njk" %} 
import java.util.Arrays
import smile.cs.*
import smile.math.MathEx

MathEx.setSeed(19650218)
int n = 128, m = 50, k = 5

double[] xTrue = new double[n]
int[] locs = MathEx.permutate(n)
for (int i = 0; i < k; i++) {
    double amp = 1.0 + MathEx.random()
    xTrue[locs[i]] = MathEx.random() < 0.5 ? amp : -amp
}

var mm = MeasurementMatrix.gaussian(m, n)
double[] y = mm.measure(xTrue)

var omp = OMP.fit(mm.phi(), y, k)
Arrays.toString(omp.support())

double[] d = omp.x().clone()
for (int i = 0; i < n; i++) d[i] -= xTrue[i]
MathEx.norm(d) / MathEx.norm(xTrue)

var cosamp = CoSaMP.fit(mm.phi(), y, k)
d = cosamp.x().clone()
for (int i = 0; i < n; i++) d[i] -= xTrue[i]
MathEx.norm(d) / MathEx.norm(xTrue)
cosamp.iter()

Measurement Matrix

MeasurementMatrix wraps the sensing operator Φ (and an optional sparsifying wavelet Ψ). Factory methods scale entries so that E[‖Φ x‖₂²] ≈ ‖x‖₂². Use measure / backProject for forward and adjoint maps, and toMatrix() for an implicit Matrix that supports both mv and tv.

  • gaussian(m, n) — i.i.d. N(0, 1/m); default choice, strongest RIP guarantees
  • bernoulli(m, n) — ±1/√m; hardware-friendly
  • partial(m, n) — random row subsample of the identity (needs a basis incoherent with the canonical one)
  • withWavelet(Wavelet) — compound A = Φ · IDWT without forming Ψ explicitly

import smile.cs.*
import smile.math.MathEx

MathEx.setSeed(0)
var g = MeasurementMatrix.gaussian(30, 100)
var b = MeasurementMatrix.bernoulli(20, 64)
var p = MeasurementMatrix.partial(20, 64)

Orthogonal Matching Pursuit

OMP greedily grows a support of size k: each step picks the column of A most correlated with the residual, then re-solves least squares on the active set (incremental QR). With a Gaussian matrix and m ≥ C k log n, exact recovery holds when the RIP constant satisfies δ2k < √2 − 1.

Use OMP.fit(A, y, k) or new OMP.Options(k, tol) for early stopping on ‖r‖₂ / ‖y‖₂. Prefer OMP when k is known and speed matters.

CoSaMP

CoSaMP maintains a 2k-candidate support, prunes to k, and re-solves least squares—yielding near-optimal guarantees and better noise tolerance than plain OMP. It is robust to moderate over-estimates of k (requires 2k < m). Call CoSaMP.fit(A, y, k) or pass CoSaMP.Options(k, maxIter, tol).

Basis Pursuit / BPDN

Basis Pursuit solves the convex program minimize ‖x‖₁ subject to A x = y (or ‖A x − y‖₂ ≤ ε for BPDN). SMILE uses a log-barrier interior-point method with CG Newton steps. Unlike the greedy methods, k need not be known. Prefer BP/BPDN for best quality under noise on small-to-medium problems.

Exact BP is more reliable when m is not too small relative to n. The example below uses a compact instance and tight options; the residual ‖A x − y‖₂ / ‖y‖₂ shows feasibility.

{% include "components/playground-extra-actions.njk" %} 
import smile.cs.*
import smile.math.MathEx
import smile.tensor.Vector

MathEx.setSeed(7777)
int n = 32, m = 20, k = 3
double[] xTrue = new double[n]
int[] locs = MathEx.permutate(n)
for (int i = 0; i < k; i++)
    xTrue[locs[i]] = (i + 1) * (MathEx.random() < 0.5 ? 1 : -1)

var mm = MeasurementMatrix.gaussian(m, n)
double[] y = mm.measure(xTrue)

var opts = new BasisPursuit.Options(0.0, 10.0, 1e-10, 300, 50, 1e-4)
var bp = BasisPursuit.fit(mm.phi(), y, opts)
bp.iter()

var Ax = mm.phi().mv(Vector.column(bp.x()))
double[] res = new double[m]
for (int i = 0; i < m; i++) res[i] = Ax.get(i) - y[i]
MathEx.norm(res) / MathEx.norm(y)

Choosing an Algorithm

  • OMP — fastest greedy method; needs a sparsity estimate; best in high SNR
  • CoSaMP — near-optimal greedy guarantees; tolerates over-estimated k and moderate noise
  • Basis Pursuit / BPDN — convex L1; no k required; strongest under noise, slowest

Aim for m ≥ 4k at least; for high-probability recovery use roughly m ≥ 4k log(n/k). Increase m if the relative error stays large.

Wavelet-Domain Sparsity

Images and audio are often dense in the time/space domain but sparse after a wavelet transform. Chain MeasurementMatrix.gaussian(m, n).withWavelet(psi) so solvers operate on the coefficient domain (A = Φ · IDWT). Recover sparse coefficients with OMP, then synthesize the signal via psi.inverse.

{% include "components/playground-extra-actions.njk" %} 
import java.util.Arrays
import smile.cs.*
import smile.math.MathEx
import smile.wavelet.HaarWavelet

MathEx.setSeed(19650218)
int n = 128, m = 50, k = 5

double[] s = new double[n]
int[] locs = MathEx.permutate(n)
for (int i = 0; i < k; i++) {
    double amp = 1.0 + MathEx.random()
    s[locs[i]] = MathEx.random() < 0.5 ? amp : -amp
}

var wm = MeasurementMatrix.gaussian(m, n).withWavelet(new HaarWavelet())
double[] y = wm.measureSparse(s)

var omp = OMP.fit(wm.toMatrix(), y, k)
Arrays.toString(omp.support())

double[] d = omp.x().clone()
for (int i = 0; i < n; i++) d[i] -= s[i]
MathEx.norm(d) / MathEx.norm(s)
