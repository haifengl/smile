Data Processing

Machine learning is all about building models from data. However, data scientists frequently talk about models and algorithms first, which very likely generates suboptimal results. The other approach is to play with the data first. Even simple statistics and plots can help us get feelings of data and problems, which more likely lead us to better modelling.

Features

A feature is an individual measurable property of an observation — also called an explanatory variable, predictor, or regressor. Choosing informative, discriminating features matters as much as choosing the algorithm. In SMILE, tabular features live in a DataFrame (or a plain double[][] / vector). For modeling, the Formula API selects and encodes columns; reusable numeric transforms such as standardization live under smile.feature.transform (see the Tutorial).

Feature engineering still needs domain knowledge: combine automated transforms with what you know about the problem. This page focuses on holding and shaping data; the Tutorial continues into Formula-based modeling.

Data Type

Statistically, attributes are qualitative (categories) or quantitative (counts and measurements), and may be measured on a nominal, ordinal, interval, or ratio scale. SMILE maps that vocabulary onto a typed schema:

DataTypes / StructType:

Physical column types (DoubleType, IntType, StringType, date/time, arrays, …). A DataFrame’s schema() is a StructType of StructFields.

Measure:

How values should be interpreted for learning and plotting. NominalScale and OrdinalScale attach category labels to integral codes; numeric columns are typically continuous (interval/ratio).

ValueVector.nominal / ordinal:

Build factorized categorical columns efficiently. Plain ValueVector.of(String…) keeps a StringVector for text-oriented work.

Many algorithms expect numeric matrices; trees and Formula-based workflows can consume nominal fields more directly. Dates are first-class for indexing and plots; strings are useful for NLP after further encoding. When you need an explicit CSV schema, you will see StructType and NominalScale again in the CSV section.

DataFrame

While some Smile algorithms take simple double[] as input, we often use the encapsulation class DataFrame. DataFrame is a two-dimensional data structure like a table with rows and columns. Each column is a ValueVector that is a one-dimensional labeled abstraction to store a sequence of values having the same type. Columns in a DataFrame may have different data types. There are concrete subclasses of ValueVector for each primitive data type and generic object types. Creating a ValueVector by passing a list of values.

Note that the nominal and ordinal methods factorize string values and store them as integral values internally, which are more efficient, compact, and friendly for machine learning algorithm. In contrast, the ValueVector.of(String...) method returns a StringVector that store string values as is, which is useful for text processing.

Indexing

We can set a row index to the data frames that must be of length the number of rows with no duplicates nor missing values. The row index serves as a unique identifier for each row in a DataFrame. It allows you to access rows efficiently with the loc() method. Compared with the normal ordinal index, the object-based row index often contains certain semantic meaning.

Java {% include "components/playground-extra-actions.njk" %} 
var df = DataFrame.of(MathEx.randn(6, 4))
var dates = Dates.range(LocalDate.of(2025,2,1), 6)
df = df.setIndex(dates)
df.loc(dates[1])
df.loc(dates[1], dates[2])

Sparse Dataset

The feature vectors could be very sparse. To save space, SparseDataset stores data in a list of lists (LIL) sparse matrix format. SparseDataset stores one list per row, where each entry stores a column index and value. Typically, these entries are kept sorted by column index for faster lookup.

SparseDataset is often used to construct the data matrix. Once the matrix is constructed, it is typically converted to a format, such as Harwell-Boeing column-compressed sparse matrix format, which is more efficient for matrix operations.

The class BinarySparseDataset is more efficient for binary sparse data. In BinarySparseDataset, each item is stored as an integer array, which are the indices of nonzero elements in ascending order.

Loading sparse files is covered under Data Import and Export: LibSVM, coordinate triple lists, and Harwell-Boeing.

To read and write files (CSV, Parquet, ARFF, JSON, sparse formats, and more), continue with Data Import and Export.
