Deep Learning

Deep learning is based on artificial neural networks with representation learning. The adjective “deep” refers to stacking many layers so that each stage transforms the input into a slightly more abstract representation. Unlike classical pipelines that rely on hand-crafted features, deep models discover useful features from data — though architecture choices such as depth, width, and regularization still matter.

SMILE’s smile-core module already ships a tabular MLP for classification and regression. The smile-deep module goes further: an idiomatic Java API over LibTorch (CPU, CUDA, and MPS), computer-vision models and transforms (smile.vision), and ONNX Runtime inference (smile.onnx). Large language models and ONNX GenAI are covered separately on LLM.

Prerequisites

Runtime requirements for smile-deep:

Java 25+
Panama FFM is used for native interop; use a JDK that matches the project’s Java toolchain.
smile_torch / LibTorch
The native smile_torch shared library and its LibTorch dependencies must be on the platform loader path: PATH (Windows), LD_LIBRARY_PATH (Linux), or DYLD_LIBRARY_PATH (macOS).
ONNX Runtime
For smile.onnx, place onnxruntime.dll / libonnxruntime.so / libonnxruntime.dylib on the same search path (ORT releases).
--enable-native-access=ALL-UNNAMED
Required when launching outside Gradle or SMILE Studio so FFM can load native code.
--add-opens=java.base/java.nio=ALL-UNNAMED
Optional but recommended if you hit buffer-interop errors; SMILE’s Gradle tests set this flag.
Java {% include "components/playground-extra-actions.njk" %} 
// Example JVM flags for a custom launcher
java --enable-native-access=ALL-UNNAMED \
     --add-opens=java.base/java.nio=ALL-UNNAMED \
     -jar myapp.jar

Tensors

Tensor is a multidimensional array backed by a native LibTorch tensor. It implements AutoCloseable — always close tensors (or use a scope) when they are no longer needed to avoid native memory leaks.

Factory Methods

Java {% include "components/playground-extra-actions.njk" %} 
import smile.deep.tensor.Tensor;

// Zeros / ones
Tensor z = Tensor.zeros(3, 4);       // shape [3,4], float32
Tensor o = Tensor.ones(2, 3);

// Random
Tensor r  = Tensor.rand(5, 5);       // uniform [0,1)
Tensor rn = Tensor.randn(5, 5);      // standard normal

// From Java arrays
float[] data = {1f, 2f, 3f, 4f};
Tensor t = Tensor.of(data, 2, 2);    // shape [2,2]

long[] ldata = {0L, 1L, 2L};
Tensor li = Tensor.of(ldata, 3);     // Int64 tensor

// Arange and eye
Tensor ar = Tensor.arange(0, 10, 1); // [0,1,...,9]
Tensor eye = Tensor.eye(4);

Indexing

smile.deep.tensor.Index provides Python-style index objects for slicing and advanced indexing.

import smile.deep.tensor.Index;

Tensor t = Tensor.rand(4, 4);

Tensor col1 = t.get(Index.Colon, Index.of(1));   // all rows, column 1
Tensor row2 = t.get(Index.of(2));                // row 2
Tensor sub  = t.get(Index.Slice(1, 3));          // rows 1–2

Tensor rowIdx = Tensor.of(rows, 2);
Tensor subset = t.get(rowIdx);                   // rows 0 and 2

AutoScope & noGradGuard

Use AutoScope with Tensor.push / Tensor.pop to batch-free many tensors. Call promoteToParent() on values that must outlive the current scope. For inference, Tensor.noGradGuard() disables gradient tracking and reduces memory use.

Java {% include "components/playground-extra-actions.njk" %} 
import smile.deep.tensor.Tensor;
import smile.util.AutoScope;

try (var scope = new AutoScope()) {
    Tensor.push(scope);
    Tensor result = Tensor.randn(8, 8).mul(2.0);
    result.promoteToParent(); // survive pop of this scope
    Tensor.pop();             // closes other tracked tensors
}

try (var guard = Tensor.noGradGuard()) {
    // Tensor output = model.forward(input);
    // no gradient graph is built
}

Options: dtype & device

Set global defaults with Tensor.setDefaultOptions, or pass a per-call Tensor.Options. There is no Device.setDefaultDevice() — prefer Device.preferredDevice() and apply it via options or model.to(device).

Java {% include "components/playground-extra-actions.njk" %} 
import smile.deep.tensor.Device;
import smile.deep.tensor.ScalarType;
import smile.deep.tensor.Tensor;
import smile.deep.tensor.Tensor.Options;

Device device = Device.preferredDevice(); // CUDA if available, else CPU

Tensor.setDefaultOptions(new Options()
        .dtype(ScalarType.Float32)
        .device(device));

// Per-tensor override
Tensor t = Tensor.ones(new Options().dtype(ScalarType.Float64), 3, 3);

// BF16 performance check (Ampere or newer)
boolean bf16 = Tensor.isBF16Supported();

Layers

All layers implement Layer, which extends Function<Tensor, Tensor> and exposes forward, a native module handle, a name, and to(Device).

Java {% include "components/playground-extra-actions.njk" %} 
// Layer interface (sketch)
public interface Layer extends Function<Tensor, Tensor> {
    Tensor forward(Tensor input);
    MemorySegment module();
    String name();
    Layer to(Device device);
}

Optimizers

Create an optimizer from a Model and learning rate. Each step is reset() → loss.backward() → step(). Note the capital A in Optimizer.Adam.

import smile.deep.Optimizer;
import smile.deep.layer.Layer;
import smile.deep.layer.SequentialBlock;

Model model = new Model(new SequentialBlock(
    Layer.relu(784, 128),
    Layer.logSoftmax(128, 10)));

Optimizer sgd   = Optimizer.SGD(model, 0.01);
Optimizer adam  = Optimizer.Adam(model, 1e-3);
Optimizer adamW = Optimizer.AdamW(model, 1e-3);

Model API

Compose a Model from a custom LayerBlock when you need architectures beyond a plain sequential stack. Register submodules with add(name, layer) so parameters are tracked for the optimizer.

Java {% include "components/playground-extra-actions.njk" %} 
import smile.deep.Model;
import smile.deep.layer.Conv2dLayer;
import smile.deep.layer.Layer;
import smile.deep.layer.LayerBlock;
import smile.deep.layer.LinearLayer;
import smile.deep.tensor.Tensor;

LayerBlock net = new LayerBlock("MyCNN") {
    private final Conv2dLayer conv1 = Layer.conv2d(1, 32, 3);
    private final LinearLayer fc = Layer.linear(32 * 13 * 13, 10);

    {
        add("conv1", conv1);
        add("fc", fc);
    }

    @Override
    public Tensor forward(Tensor input) {
        Tensor h = conv1.forward(input);
        h = h.relu_();
        h = Layer.maxPool2d(2).forward(h);
        h = h.view(h.size(0), -1);
        return fc.forward(h);
    }
};

Model model = new Model(net);

Datasets & Sampling

Build mini-batch datasets from arrays with Dataset.of, or load IDX MNIST with Dataset.mnist. Dataset itself is Iterable<SampleBatch> — each iterator reshuffles. Every SampleBatch exposes data() and target() tensors.

Java {% include "components/playground-extra-actions.njk" %} 
import smile.deep.Dataset;
import smile.deep.SampleBatch;

float[][] features = /* ... */;
int[] labels = /* ... */;
Dataset ds = Dataset.of(features, labels, 64);
// also: Dataset.of(double[][], int[], batch)
// MNIST IDX: Dataset.mnist("data/mnist", true, 64);

for (SampleBatch batch : ds) {
    var x = batch.data();
    var y = batch.target();
    // train step...
    batch.close();
}

End-to-End Examples

Gentle MNIST MLP

Pick a device with Device.preferredDevice(), set tensor defaults via Tensor.setDefaultOptions (there is no setDefaultDevice), wrap arrays with Dataset.of, and train with NLL loss over a log-softmax head.

Java {% include "components/playground-extra-actions.njk" %} 
import java.util.Map;
import org.apache.commons.csv.CSVFormat;
import smile.deep.*;
import smile.deep.layer.*;
import smile.deep.metric.*;
import smile.deep.tensor.*;
import smile.io.Read;

Device device = Device.preferredDevice();
Tensor.setDefaultOptions(new Tensor.Options().device(device));

Model net = new Model(new SequentialBlock(
        Layer.relu(784, 64, 0.5),
        Layer.relu(64, 32),
        Layer.logSoftmax(32, 10)));

System.out.println(net);
net.to(device);

CSVFormat format = CSVFormat.Builder.create().setDelimiter(' ').build();
double[][] x = Read.csv("data/mnist/mnist2500_X.txt", format).toArray();
int[] y = Read.csv("data/mnist/mnist2500_labels.txt", format)
        .column(0).toIntArray();
Dataset dataset = Dataset.of(x, y, 64);

Optimizer optimizer = Optimizer.SGD(net, 0.01);
Loss loss = Loss.nll();
net.train(100, optimizer, loss, dataset);

try (var guard = Tensor.noGradGuard()) {
    Map<String, Double> metrics = net.eval(dataset,
            new Accuracy(),
            new Precision(Averaging.Micro),
            new Precision(Averaging.Macro),
            new Recall(Averaging.Weighted));
    for (var entry : metrics.entrySet()) {
        System.out.format("Training %s = %.2f%%%n",
                entry.getKey(), 100 * entry.getValue());
    }
}

Manual Training Loop

When you need full control, drive epochs yourself with optimizer.reset(), backward(), and step(). Alternatively, call Model.train as in the LeNet example below.

Java {% include "components/playground-extra-actions.njk" %} 
import smile.deep.*;
import smile.deep.layer.*;
import smile.deep.tensor.Tensor;

SequentialBlock mlp = new SequentialBlock(
    Layer.relu(784, 256),
    Layer.relu(256, 128),
    Layer.logSoftmax(128, 10));
Model model = new Model(mlp);

Optimizer optimizer = Optimizer.Adam(model, 1e-3);
Loss criterion = Loss.nll();

// Dataset trainDataset = Dataset.of(x, y, 64);
for (int epoch = 0; epoch < 5; epoch++) {
    for (SampleBatch batch : trainDataset) {
        optimizer.reset();
        Tensor logp = model.forward(batch.data());
        Tensor loss = criterion.apply(logp, batch.target());
        loss.backward();
        optimizer.step();
        batch.close();
    }
}

LeNet with Model.train

A convolutional LeNet on MNIST. Load IDX files with Dataset.mnist(path, trainMode, batch) (shape [N, 1, 28, 28]), then call the high-level Model.train API.

Java {% include "components/playground-extra-actions.njk" %} 
import smile.deep.*;
import smile.deep.activation.LogSoftmax;
import smile.deep.activation.ReLU;
import smile.deep.layer.*;
import smile.deep.metric.Accuracy;
import smile.deep.tensor.Tensor;

Dataset mnistTrainDataset = Dataset.mnist("data/mnist", true, 64);
Dataset mnistTestDataset = Dataset.mnist("data/mnist", false, 64);

LayerBlock net = new LayerBlock("LeNet") {
    private final Conv2dLayer conv1 = Layer.conv2d(1, 6, 5);
    private final Conv2dLayer conv2 = Layer.conv2d(6, 16, 5);
    private final LinearLayer fc1 = Layer.linear(16 * 4 * 4, 120);
    private final LinearLayer fc2 = Layer.linear(120, 84);
    private final LinearLayer fc3 = Layer.linear(84, 10);
    private final MaxPool2dLayer pool = Layer.maxPool2d(2);

    {
        add("conv1", conv1); add("conv2", conv2);
        add("fc1", fc1); add("fc2", fc2); add("fc3", fc3);
    }

    @Override
    public Tensor forward(Tensor input) {
        Tensor x = pool.forward(
                new ReLU(true).forward(conv1.forward(input)));
        x = pool.forward(new ReLU(true).forward(conv2.forward(x)));
        x = x.view(x.size(0), -1);
        x = new ReLU(true).forward(fc1.forward(x));
        x = new ReLU(true).forward(fc2.forward(x));
        return new LogSoftmax().forward(fc3.forward(x));
    }
};

Model lenet = new Model(net);
lenet.train(
    10,
    Optimizer.SGD(lenet, 0.01, 0.9, 0.0, 0.0, false),
    Loss.nll(),
    mnistTrainDataset,
    mnistTestDataset,
    null,
    new Accuracy());

EfficientNet Pretrained Inference

Download weights such as efficientnet_v2_s.pt into model/EfficientNet/ (or pass a custom path). The first CUDA inference is often slower because the driver context and allocator warm up.

Java {% include "components/playground-extra-actions.njk" %} 
import java.io.File;
import javax.imageio.ImageIO;
import smile.deep.tensor.Device;
import smile.deep.tensor.Tensor;
import smile.vision.EfficientNet;
import smile.vision.ImageNet;

Device device = Device.preferredDevice();
var model = EfficientNet.V2S();
model.to(device);
model.eval();

var lenna = ImageIO.read(new File("data/image/Lenna.png"));
var panda = ImageIO.read(new File("data/image/panda.jpg"));

try (var guard = Tensor.noGradGuard()) {
    long start = System.nanoTime();
    var output = model.forward(panda);
    System.out.println("1st run: "
            + (System.nanoTime() - start) / 1_000_000 + "ms");

    start = System.nanoTime();
    output = model.forward(lenna, panda);
    System.out.println("2nd run: "
            + (System.nanoTime() - start) / 1_000_000 + "ms");

    var topk = output.topk(5);
    topk._2().to(Device.CPU());
    String[] images = {"Lenna", "Panda"};
    for (int i = 0; i < 2; i++) {
        System.out.println("======== " + images[i] + " ========");
        for (int j = 0; j < 5; j++) {
            System.out.println(
                    ImageNet.labels[topk._2().getInt(i, j)]);
        }
    }
}

Execution Providers

Append providers on SessionOptions before creating the session. If a provider is missing from the ORT build, creation fails — check Environment.availableProviders() first.

Provider helperTypical use
appendCudaExecutionProvider(deviceId)NVIDIA GPU inference
appendTensorRTExecutionProvider(deviceId)TensorRT-accelerated GPU (when built into ORT)
CPU (default)Always available; no append needed

Resource Management

InferenceSession, OrtValue, SessionOptions, RunOptions, and Environment all implement AutoCloseable. Prefer try-with-resources. Output arrays from session.run must be closed explicitly (the session does not own them).

Tutorial: ResNet-50

Load an image as NCHW float32 (resize, ImageNet mean/std), run the session, then softmax / argmax. Preprocessing details vary by export; keep the tensor layout consistent with the model’s input name and shape.

Tutorial: CUDA Execution Provider

Java {% include "components/playground-extra-actions.njk" %} 
import java.util.List;
import java.util.Map;
import smile.onnx.*;

List<String> providers = Environment.availableProviders();

try (var opts = new SessionOptions()) {
    if (providers.contains("CUDAExecutionProvider")) {
        opts.appendCudaExecutionProvider(0);
    }
    opts.setGraphOptimizationLevel(GraphOptimizationLevel.ENABLE_ALL);

    try (var session = InferenceSession.create("resnet50.onnx", opts);
         OrtValue input = OrtValue.fromFloatArray(
                 new float[3 * 224 * 224], new long[]{1, 3, 224, 224})) {
        OrtValue[] outputs = session.run(
                Map.of(session.inputNames().getFirst(), input));
        for (OrtValue v : outputs) v.close();
    }
}
