Graph Data Structure

Many SMILE algorithms (Isomap, UMAP, spectral clustering, …) build graphs internally. The smile.graph package exposes them as first-class structures: vertices linked by directed or undirected edges, optionally weighted.

Storage is either an AdjacencyList (good for sparse graphs) or an AdjacencyMatrix (fast random edge access). Both implement Graph. For k-NN graphs used by manifold methods, see also NearestNeighborGraph.

Graph.dot() returns Graphviz DOT; paste it into viz-js.com to draw the graph. Optional name and per-vertex labels apply to the first labels; remaining vertices keep their integer IDs.

{% include "components/playground-extra-actions.njk" %} 
import smile.graph.*

var graph = new AdjacencyList(8)
graph.addEdge(0, 2)
graph.addEdge(1, 7)
graph.addEdge(2, 6)
graph.addEdge(7, 4)
graph.addEdge(3, 4)
graph.addEdge(3, 5)
graph.addEdge(5, 4)

String[] label = {"a", "b", "c", "d"}
graph.dot("SMILEGraph", label)

Graph Traversal

Breadth-first and depth-first search visit every vertex systematically and build spanning trees used by later algorithms. bfs(VertexVisitor) and dfs(VertexVisitor) call your visitor at each vertex.

{% include "components/playground-extra-actions.njk" %} 
import smile.graph.*

var graph = new AdjacencyList(8)
graph.addEdge(0, 2)
graph.addEdge(1, 7)
graph.addEdge(2, 6)
graph.addEdge(7, 4)
graph.addEdge(3, 4)
graph.addEdge(3, 5)
graph.addEdge(5, 4)

graph.dfs(i -> println("Visiting vertex " + i))

Connected Components

A connected component of an undirected graph is a maximal connected subgraph. bfcc() and dfcc() return a 2-D array whose rows are the vertex IDs of each component. (Directed strongly connected components need Kosaraju or Tarjan; ordinary DFS/BFS is not enough.)

{% include "components/playground-extra-actions.njk" %} 
import java.util.Arrays
import smile.graph.*

var graph = new AdjacencyList(8)
graph.addEdge(0, 2)
graph.addEdge(1, 7)
graph.addEdge(2, 6)
graph.addEdge(7, 4)
graph.addEdge(3, 4)
graph.addEdge(3, 5)
graph.addEdge(5, 4)

Arrays.deepToString(graph.bfcc())
Arrays.deepToString(graph.dfcc())

[[0, 2, 6], [1, 3, 4, 5, 7]]
[[0, 2, 6], [1, 3, 4, 5, 7]]

Topological Sort

On a directed acyclic graph (DAG), a topological order lists vertices so every edge u → v has u before v—the classic “tasks with prerequisites” schedule. dfsort() and bfsort() return such an order (they throw on undirected graphs).

Minimum Spanning Tree

An MST connects all vertices of a weighted undirected graph with no cycles and minimum total weight. prim(List<Edge>) runs Prim’s algorithm, fills the edge list, and returns the cost.

{% include "components/playground-extra-actions.njk" %} 
import java.util.ArrayList
import smile.graph.*

var graph = new AdjacencyMatrix(6)
graph.addEdge(0, 1, 0.41)
graph.addEdge(1, 2, 0.51)
graph.addEdge(2, 3, 0.50)
graph.addEdge(4, 3, 0.36)
graph.addEdge(3, 5, 0.38)
graph.addEdge(3, 0, 0.45)
graph.addEdge(0, 5, 0.29)
graph.addEdge(5, 4, 0.21)
graph.addEdge(1, 4, 0.32)
graph.addEdge(4, 2, 0.32)
graph.addEdge(5, 1, 0.29)

var mst = new ArrayList<Graph.Edge>()
graph.prim(mst)
mst

Shortest Path

dijkstra() returns all-pairs shortest-path distances; dijkstra(source) is the single-source case. Manifold learners often use these geodesic distances instead of raw pairwise Euclidean distance.

Travelling Salesman Problem

TSP asks for the shortest tour that visits every vertex once and returns to the start—an NP-hard classic. SMILE’s Held–Karp dynamic program finds the optimum in Θ(n2 2n) time, far better than brute-force Θ(n!), and tsp() is a branch-and-bound exact solver for moderate sizes.

{% include "components/playground-extra-actions.njk" %} 
import java.util.Arrays
import smile.graph.*

var graph = new AdjacencyMatrix(6)
graph.addEdge(0, 1, 0.41)
graph.addEdge(1, 2, 0.51)
graph.addEdge(2, 3, 0.50)
graph.addEdge(4, 3, 0.36)
graph.addEdge(3, 5, 0.38)
graph.addEdge(3, 0, 0.45)
graph.addEdge(0, 5, 0.29)
graph.addEdge(5, 4, 0.21)
graph.addEdge(1, 4, 0.32)
graph.addEdge(4, 2, 0.32)
graph.addEdge(5, 1, 0.29)

int[] tour = graph.heldKarp()
Arrays.toString(tour)
graph.getPathDistance(tour)

Arrays.toString(graph.tsp())

[0, 5, 1, 4, 2, 3, 0]

Maximum Flow

AdjacencyMatrix.pushRelabel implements the push–relabel max-flow algorithm: it maintains a preflow and converts it into a maximum feasible flow from source to sink by local push and relabel steps. The method fills a flow matrix and returns the max-flow value.

{% include "components/playground-extra-actions.njk" %} 
import smile.graph.*

var graph = new AdjacencyMatrix(6, true)
graph.addEdge(0, 1, 2)
graph.addEdge(0, 2, 9)
graph.addEdge(1, 2, 1)
graph.addEdge(1, 3, 0)
graph.addEdge(1, 4, 0)
graph.addEdge(2, 4, 7)
graph.addEdge(3, 5, 7)
graph.addEdge(4, 5, 4)

double[][] flow = new double[6][6]
graph.pushRelabel(flow, 0, 5)

4.0
