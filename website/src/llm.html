Large Language Model

A large language model (LLM) is a computational model notable for its ability to achieve general-purpose language generation and other NLP tasks such as classification. Transformer, the state-of-the-art LLM architecture, is based on the multi-head attention mechanism. Text is converted to numerical representations called tokens, and each token is converted into a vector via looking up from a word embedding table. At each layer, each token is then contextualized within the scope of the context window with other (unmasked) tokens via a parallel multi-head softmax-based attention mechanism allowing the signal for key tokens to be amplified and less important tokens to be diminished. GPTs (Generative pre-trained transformers) are based on the decoder-only transformer architecture. Each generation of GPT models is significantly more capable than the previous, due to increased model size (number of trainable parameters) and larger training data.

Llama 3.1

SMILE provides an inference implementation of Llama 3.1 from Meta AI. To build a model instance, call Llama.build() with the Hugging Face checkpoint directory, the tokenizer model file path, maximum batch size, maximum sequence length, and CUDA device id:

Java {% include "components/playground-extra-actions.njk" %} 

import smile.llm.model.llama.Llama;
import smile.llm.Message;

var llama = Llama.build(
    "model/Llama-3.1-8B-Instruct",
    "model/Llama-3.1-8B-Instruct/original/tokenizer.model",
    /*maxBatchSize=*/ 4,
    /*maxSeqLen=*/    8192,
    /*deviceId=*/     (byte) 0    // CUDA:0
);

For a pretrained model, call generate() with a batch of prompts to generate text. For fine-tuned chat models, call chat() to generate conversation responses.

Java {% include "components/playground-extra-actions.njk" %} 

var reply = llama.chat(
    new Message[]{
        Message.system("You are a helpful assistant."),
        Message.user("Explain gradient descent in one paragraph.")
    },
    /*maxGenLen=*/ 256,
    /*temperature=*/ 0.7,
    /*topp=*/ 0.9,
    /*logprobs=*/ false,
    /*seed=*/ 0L,
    /*listener=*/ null,
    /*cancelRequested=*/ null
);

System.out.println(reply.content());

For streaming output, pass a GenerationListener that receives tokens as they are generated. The cancelRequested supplier can signal early termination.

Qwen3

SMILE also supports Qwen3 models, including the hybrid Qwen3.5 architecture (Gated DeltaNet + full attention). Qwen checkpoints use a Hugging Face tokenizer.json instead of a SentencePiece tokenizer.model, so Qwen.build() takes only the checkpoint directory (the tokenizer is resolved automatically).

Java {% include "components/playground-extra-actions.njk" %} 

import smile.llm.model.qwen.Qwen;
import smile.llm.Message;

var qwen = Qwen.build(
    "model/Qwen3.8-27B",
    /*maxBatchSize=*/ 4,
    /*maxSeqLen=*/    8192,
    /*deviceId=*/     (byte) 0    // CUDA:0
);

var reply = qwen.chat(
    new Message[]{
        Message.system("You are a helpful assistant."),
        Message.user("What are the key differences between Java and Kotlin?")
    },
    /*maxGenLen=*/ 512,
    /*temperature=*/ 0.7,
    /*topp=*/ 0.9,
    /*logprobs=*/ false,
    /*seed=*/ 0L,
    /*listener=*/ null,
    /*cancelRequested=*/ null
);

System.out.println(reply.content());

For multi-GPU tensor parallelism, use the overloads that accept a ParallelConfig. Native FP8 quantization (e.g. Qwen/Qwen3.8-27B-FP8) is supported on Hopper+ GPUs (sm_90+).
