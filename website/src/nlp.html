Natural Language Processing

The smile-nlp module covers the classical text-processing pipeline: Unicode normalization, paragraph / sentence / word splitting, stemming, part-of-speech tagging, dictionaries, collocation extraction, relevance ranking, word embeddings, and lightweight concept taxonomies.

This guide is for engineered NLP features and retrieval — not large language models. For LLM serving and generation APIs, see Large Language Models. Trainable sequence labelers (HMM / CRF) live on Sequence Labeling; classic bag-of-words classifiers are on Classification.

Quick Start

A typical preprocessing path is normalize → paragraphs → sentences → tokens → POS tags → stems. Filter on PennTreebankPOS.open when you only want content words. Use one PorterStemmer per thread; the default HMM tagger is safe to share.

{% include "components/playground-extra-actions.njk" %} 
import smile.nlp.normalizer.SimpleNormalizer;
import smile.nlp.tokenizer.*;
import smile.nlp.stemmer.PorterStemmer;
import smile.nlp.pos.*;

String raw = "Machine learning is a subfield of AI. Deep learning uses neural nets.";
String text = SimpleNormalizer.getInstance().normalize(raw);

var paragraphs = SimpleParagraphSplitter.getInstance();
var sentences = SimpleSentenceSplitter.getInstance();
var tokenizer = new SimpleTokenizer();
var tagger = HMMPOSTagger.getDefault();
var stemmer = new PorterStemmer();

for (String para : paragraphs.split(text)) {
    for (String sent : sentences.split(para)) {
        String[] tokens = tokenizer.split(sent);
        PennTreebankPOS[] tags = tagger.tag(tokens);
        for (int i = 0; i < tokens.length; i++) {
            if (tags[i].open) {
                System.out.printf("%-16s %-6s %s%n",
                    tokens[i], tags[i], stemmer.stem(tokens[i].toLowerCase()));
            }
        }
    }
}

Core Types

The root smile.nlp package holds the document model, collocation records, an in-memory corpus, and word-embedding loaders.

Text is a lightweight immutable record with optional title and body. Factory methods are Text.of(content) and Text.of(title, content).

Bigram and NGram

Bigram and NGram are records for word pairs and n-word phrases, optionally carrying raw frequency and association scores. They are the return types of collocation extractors.

Java {% include "components/playground-extra-actions.njk" %} 
import smile.nlp.Bigram;
import smile.nlp.NGram;

Bigram b = new Bigram("machine", "learning");
NGram n = new NGram(new String[]{"deep", "learning"});
System.out.println(b);
System.out.println(n);

SimpleCorpus

Corpus is the indexed-document interface. SimpleCorpus is the built-in in-memory implementation: it tokenizes on insert and keeps term / bigram tables for collocations and relevance search. Scala and Kotlin helpers build a corpus from a sequence of strings.

{% include "components/playground-extra-actions.njk" %} 
import smile.nlp.SimpleCorpus;

SimpleCorpus corpus = new SimpleCorpus();
corpus.add(corpus.doc("SMILE is a fast machine learning library."));
corpus.add(corpus.doc("Deep learning uses neural networks."));
System.out.println(corpus.docCount());
System.out.println(corpus.count("learning"));

Word2Vec

Word2Vec loads pretrained embeddings in Word2vec binary format (Word2Vec.of) or GloVe text format (Word2Vec.glove). Look up vectors with apply or lookup, and compare tokens with cosine similarity.

Java {% include "components/playground-extra-actions.njk" %} 
import java.nio.file.Path;
import smile.nlp.Word2Vec;

// Word2vec binary or GloVe text
Word2Vec w2v = Word2Vec.of(Path.of("GoogleNews-vectors-negative300.bin"));
// Word2Vec glove = Word2Vec.glove(Path.of("glove.6B.100d.txt"));

float[] vec = w2v.apply("king");
w2v.lookup("king").ifPresent(v -> System.out.println(v.length));
w2v.similarity("king", "queen").ifPresent(System.out::println);
System.out.println(w2v.size() + " x " + w2v.dimension());

Tokenizers

The tokenizer package splits text at three levels. All splitter interfaces extend Function<String, String[]>, so they compose in streams. Prefer the Simple* and PennTreebank singletons for English; BreakIterator* variants are locale-aware but not thread-safe.

ClassLevelNotes
SimpleParagraphSplitterParagraphBlank lines; singleton
SimpleSentenceSplitterSentenceEnglish heuristics + abbreviations; singleton
BreakIteratorSentenceSplitterSentenceLocale-aware; not thread-safe
SimpleTokenizerWordExpands contractions; thread-safe
PennTreebankTokenizerWordPenn Treebank conventions; singleton
BreakIteratorTokenizerWordLocale-aware; not thread-safe

Scala and Kotlin enrich strings with sentences and words(filter). The filter may be none, default, comprehensive, google, mysql, or a comma-separated custom stop list.

import smile.nlp.tokenizer.*;

String text = "Dr. Smith lives in the U.S. He works at NASA.";

Tokenizer tok = new SimpleTokenizer();
for (String s : sents) {
    System.out.println(String.join(" | ", tok.split(s)));

Penn Treebank vs SimpleTokenizer

Package-private EnglishAbbreviations backs the English splitters: SimpleSentenceSplitter and both word tokenizers consult it so titles and Latin abbreviations (Dr., etc., U.S., …) are not treated as sentence or token boundaries. Tokenizer simple = new SimpleTokenizer();
Tokenizer ptb = PennTreebankTokenizer.getInstance();

Start with PorterStemmer. Switch to LancasterStemmer when vocabulary size is the bottleneck. Porter does not lower-case input; Lancaster lower-cases and strips non-letters automatically.

stripPluralParticiple

PorterStemmer.stripPluralParticiple applies only the plural / participle step (Porter step 1a/1b-style), useful when you want light normalization without full stemming. Short words such as was, has, his, and this are preserved.

System.out.println(porter.stripPluralParticiple("running"));

Part-of-Speech Tagging

HMMPOSTagger.getDefault() loads a pretrained first-order HMM over the Penn Treebank tag set. PennTreebankPOS.open marks content (open-class) tags. Package-private RegexPOSTagger is the OOV pre-classifier used inside the HMM for numbers, URLs, and e-mails. To train general HMM / CRF sequence models, see Sequence Labeling.

Open vs Closed Class

Open-class tags (nouns, verbs, adjectives, adverbs, …) have open == true and are the usual candidates for bag-of-words and keyword features. Closed-class tags (determiners, prepositions, pronouns, …) have open == false. PennTreebankPOS.getValue(String) parses corpus tag strings, including punctuation symbols mapped to named constants (e.g. "." → SENT).

Java {% include "components/playground-extra-actions.njk" %} 
import smile.nlp.pos.PennTreebankPOS;

PennTreebankPOS nn = PennTreebankPOS.getValue("NN");
PennTreebankPOS dot = PennTreebankPOS.getValue(".");
System.out.println(nn + " open=" + nn.open);
System.out.println(dot + " open=" + dot.open);
System.out.println(PennTreebankPOS.DT.open);

. open=false

RegexPOSTagger (internal OOV rules)

RegexPOSTagger is package-private and used by HMMPOSTagger for out-of-vocabulary tokens. Its tag(String) returns an Optional<PennTreebankPOS>: cardinal / comma-formatted numbers → CD; phone numbers, URLs, and e-mails → NN; empty when no pattern matches.

EnglishPOSLexicon

EnglishPOSLexicon.get(word) looks up ~200k English words (Moby + WordNet) and returns an Optional of candidate Penn tags in priority order.

    System.out.println("primary=" + tags[0]);

Custom HMM POS Model

Train a domain tagger with HMMPOSTagger.fit on aligned token / tag arrays. On the bundled WSJ Treebank data, 10-fold CV error is about 5 %. Package-private HMMPOSTagger.read loads *.POS files (word/TAG lines) when you train from inside the module; otherwise build the arrays yourself. For general HMM / CRF training APIs, see Sequence Labeling.

// sentences: String[][] tokens; labels: PennTreebankPOS[][]

String[][] x = {

    {"Dogs", "bark", "."}

Collocations

Collocations are statistically significant word co-occurrences. SimpleCorpus exposes two bigram overloads ranked by log-likelihood ratio (−2 log λ, χ² with 1 df): bigrams(k, minFreq) returns the top-k pairs, and bigrams(p, minFreq) returns all pairs whose p-value is below p (0 < p < 1). minFrequency is exclusive (count > minFrequency). NGram.apriori mines frequent phrases of length up to maxN from already-tokenized sentences.

{% include "components/playground-extra-actions.njk" %} 
import smile.nlp.SimpleCorpus;

SimpleCorpus corpus = new SimpleCorpus();
corpus.add(corpus.doc("Machine learning is part of artificial intelligence."));
corpus.add(corpus.doc("Deep learning is a type of machine learning."));
corpus.add(corpus.doc("Neural networks power deep learning systems."));

System.out.println("--- top-k ---");
corpus.bigrams(5, 1).forEach(b ->
    System.out.println(b.w1() + " " + b.w2() + "  score=" + b.score()));

System.out.println("--- p-value ---");
corpus.bigrams(0.01, 1).forEach(b ->
    System.out.println(b.w1() + " " + b.w2() + "  score=" + b.score()));

Parameter Tuning

ParameterGuidance
minFrequencyExclusive lower bound. Tiny corpora: 1–2; 1k–10k tokens: 2–5; 10k–100k: 5–10; larger: 10–50
k (top-k)Fixed-size feature / display lists; start around 20
p0.05 lenient; 0.01 / 0.001 stricter; 0.0001 very strict

For n-grams longer than two, tokenize sentences first, then call NGram.apriori(sentences, maxN, minFreq). Index result[n] holds the n-grams (sorted by descending count). Scala / Kotlin ngram helpers accept raw text and handle sentence splitting and stemming internally.

{% include "components/playground-extra-actions.njk" %} 
import java.util.List;
import smile.nlp.NGram;
import smile.nlp.tokenizer.*;

String[] docs = {
    "Machine learning is part of artificial intelligence.",
    "Deep learning is a type of machine learning."
};
var splitter = SimpleSentenceSplitter.getInstance();
var tokenizer = new SimpleTokenizer();
List<String[]> sentences = java.util.Arrays.stream(docs)
    .flatMap(d -> java.util.Arrays.stream(splitter.split(d)))
    .map(tokenizer::split)
    .toList();

NGram[][] result = NGram.apriori(sentences, 3, 2);
for (NGram g : result[2]) {
    System.out.println(String.join(" ", g.words()) + "  count=" + g.count());
}

Relevance Ranking

Plug a RelevanceRanker into Corpus.search to rank documents for a query string or token array. TFIDF is classic weighted bag-of-words; BM25 is Okapi BM25+ for ad-hoc retrieval. Default new BM25() uses k1=1.2, b=0.75, delta=1.0; tune with new BM25(k1, b, delta) (set delta=0 for classic BM25 without the BM25+ floor).

CriterionTF-IDFBM25
SimplicityStraightforward formulaSlightly more parameters
Long documentsBias toward long docsLength-normalized by b
TF saturationNone (linear in tf)Logarithmic via k1
TunableOne parameter (a)Three (k1, b, delta)
Recommended forPrototypes, small corporaProduction search, larger corpora

Taxonomy

A Taxonomy is an ordered IS-A tree of Concept nodes. Each concept carries a synonym set via keywords(). TaxonomicDistance provides edge-counting distance d(), normalized distance, and three similarity measures (Wu–Palmer, Leacock–Chodorow, Lin). d() counts edges through the LCA — it is not Wu–Palmer; call wuPalmer separately for that similarity.

Parsing with Taxonomy.of

Taxonomy.of(String) builds a tree from indented text: 4 spaces (or one tab) per level, comma-separated synonyms on a line, # comments allowed. The first non-blank line is the root.

Java {% include "components/playground-extra-actions.njk" %} 
import smile.nlp.taxonomy.*;

Taxonomy taxonomy = Taxonomy.of("""
    animal
        mammal, warm-blooded
            dog, canine
            cat, feline
        reptile
            snake
    """);
System.out.println(taxonomy);
System.out.println(taxonomy.getConcept("dog") == taxonomy.getConcept("canine"));
System.out.println(taxonomy.getConcept("dog").keywords());

├── [mammal, warm-blooded]
│   ├── [canine, dog]
│   └── [cat, feline]
└── [reptile]
