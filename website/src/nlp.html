Natural Language Processing

The smile-nlp module covers the classical text-processing pipeline: Unicode normalization, paragraph / sentence / word splitting, stemming, part-of-speech tagging, dictionaries, collocation extraction, relevance ranking, word embeddings, and lightweight concept taxonomies.

This guide is for engineered NLP features and retrieval — not large language models. For LLM serving and generation APIs, see Large Language Models. Trainable sequence labelers (HMM / CRF) live on Sequence Labeling; classic bag-of-words classifiers are on Classification.

Quick Start

A typical preprocessing path is normalize → paragraphs → sentences → tokens → POS tags → stems. Filter on PennTreebankPOS.open when you only want content words. Use one PorterStemmer per thread; the default HMM tagger is safe to share.

{% include "components/playground-extra-actions.njk" %} 
import smile.nlp.normalizer.SimpleNormalizer;
import smile.nlp.tokenizer.*;
import smile.nlp.stemmer.PorterStemmer;
import smile.nlp.pos.*;

String raw = "Machine learning is a subfield of AI. Deep learning uses neural nets.";
String text = SimpleNormalizer.getInstance().normalize(raw);

var paragraphs = SimpleParagraphSplitter.getInstance();
var sentences = SimpleSentenceSplitter.getInstance();
var tokenizer = new SimpleTokenizer();
var tagger = HMMPOSTagger.getDefault();
var stemmer = new PorterStemmer();

for (String para : paragraphs.split(text)) {
    for (String sent : sentences.split(para)) {
        String[] tokens = tokenizer.split(sent);
        PennTreebankPOS[] tags = tagger.tag(tokens);
        for (int i = 0; i < tokens.length; i++) {
            if (tags[i].open) {
                System.out.printf("%-16s %-6s %s%n",
                    tokens[i], tags[i], stemmer.stem(tokens[i].toLowerCase()));
            }
        }
    }
}

Core Types

The root smile.nlp package holds the document model, collocation records, an in-memory corpus, and word-embedding loaders.

Text

Text is a lightweight immutable record with optional title and body. Factory methods are Text.of(content) and Text.of(title, content).

{% include "components/playground-extra-actions.njk" %} 
import smile.nlp.Text;

Text doc = Text.of("Machine learning is a subfield of AI.");
Text titled = Text.of("Overview", "Machine learning is a subfield of AI.");
System.out.println(doc.content());
System.out.println(titled.title());

Bigram and NGram

Bigram and NGram are records for word pairs and n-word phrases, optionally carrying raw frequency and association scores. They are the return types of collocation extractors.

Java {% include "components/playground-extra-actions.njk" %} 
import smile.nlp.Bigram;
import smile.nlp.NGram;

Bigram b = new Bigram("machine", "learning");
NGram n = new NGram(new String[]{"deep", "learning"});
System.out.println(b);
System.out.println(n);

Bigram{w1='machine', w2='learning', ...}
NGram{words=[deep, learning], ...}

SimpleCorpus

Corpus is the indexed-document interface. SimpleCorpus is the built-in in-memory implementation: it tokenizes on insert and keeps term / bigram tables for collocations and relevance search. Scala and Kotlin helpers build a corpus from a sequence of strings.

{% include "components/playground-extra-actions.njk" %} 
import smile.nlp.SimpleCorpus;

SimpleCorpus corpus = new SimpleCorpus();
corpus.add(corpus.doc("SMILE is a fast machine learning library."));
corpus.add(corpus.doc("Deep learning uses neural networks."));
System.out.println(corpus.docCount());
System.out.println(corpus.count("learning"));

Word2Vec

Word2Vec loads pretrained embeddings in Word2vec binary format (Word2Vec.of) or GloVe text format (Word2Vec.glove). Look up vectors with apply or lookup, and compare tokens with cosine similarity.

Java {% include "components/playground-extra-actions.njk" %} 
import java.nio.file.Path;
import smile.nlp.Word2Vec;

// Word2vec binary or GloVe text
Word2Vec w2v = Word2Vec.of(Path.of("GoogleNews-vectors-negative300.bin"));
// Word2Vec glove = Word2Vec.glove(Path.of("glove.6B.100d.txt"));

float[] vec = w2v.apply("king");
w2v.lookup("king").ifPresent(v -> System.out.println(v.length));
w2v.similarity("king", "queen").ifPresent(System.out::println);
System.out.println(w2v.size() + " x " + w2v.dimension());

Normalizer

SimpleNormalizer is a thread-safe singleton that cleans heterogeneous Unicode before tokenization. Always normalize text from the web, PDFs, or user input to avoid spurious tokens from encoding variants.

StepDetail

WhitespaceStrip, trim, and compress whitespace

DashesEm-dash, en-dash, etc. → -

Tokenizers

The tokenizer package splits text at three levels. All splitter interfaces extend Function<String, String[]>, so they compose in streams. Prefer the Simple* and PennTreebank singletons for English; BreakIterator* variants are locale-aware but not thread-safe.

ClassLevelNotes
SimpleParagraphSplitterParagraphBlank lines; singleton
SimpleSentenceSplitterSentenceEnglish heuristics + abbreviations; singleton
BreakIteratorSentenceSplitterSentenceLocale-aware; not thread-safe
SimpleTokenizerWordExpands contractions; thread-safe
PennTreebankTokenizerWordPenn Treebank conventions; singleton
BreakIteratorTokenizerWordLocale-aware; not thread-safe

Scala and Kotlin enrich strings with sentences and words(filter). The filter may be none, default, comprehensive, google, mysql, or a comma-separated custom stop list.

{% include "components/playground-extra-actions.njk" %} 
import smile.nlp.tokenizer.*;

String text = "Dr. Smith lives in the U.S. He works at NASA.";
String[] sents = SimpleSentenceSplitter.getInstance().split(text);
Tokenizer tok = new SimpleTokenizer();
for (String s : sents) {
    System.out.println(String.join(" | ", tok.split(s)));
}

Both stemmers implement Stemmer extends Function<String,String> for stream use. Porter is moderate and not thread-safe (one instance per thread). Lancaster is aggressive and shareable; pass true to also strip prefixes.

Part-of-Speech Tagging

HMMPOSTagger.getDefault() loads a pretrained first-order HMM over the Penn Treebank tag set. PennTreebankPOS.open marks content (open-class) tags. RegexPOSTagger is a rule-based pre-classifier for numbers, URLs, and e-mails. To train custom HMM or CRF sequence models, see Sequence Labeling.

ClassRole
PennTreebankPOS45-tag enum; open distinguishes content vs function words
HMMPOSTaggerPretrained HMM tagger; serializable
RegexPOSTaggerRule-based pre-classifier for numbers, URLs, e-mails
EnglishPOSLexicon~200k word lexicon (Moby + WordNet)

HMMPOSTagger tagger = HMMPOSTagger.getDefault();
String[] tokens = {"The", "cat", "sat", "on", "the", "mat", "."};

for (int i = 0; i < tokens.length; i++) {
    System.out.printf("%-12s %s%n", tokens[i], tags[i]);

Collocations

Collocations are statistically significant word co-occurrences. SimpleCorpus.bigrams ranks adjacent pairs by likelihood ratio; NGram.apriori mines frequent phrases of length up to maxN from already-tokenized sentences.

{% include "components/playground-extra-actions.njk" %} 
import smile.nlp.SimpleCorpus;

SimpleCorpus corpus = new SimpleCorpus();
corpus.add(corpus.doc("Machine learning is part of artificial intelligence."));
corpus.add(corpus.doc("Deep learning is a type of machine learning."));
corpus.add(corpus.doc("Neural networks power deep learning systems."));

corpus.bigrams(5, 1).forEach(b ->
    System.out.println(b.w1() + " " + b.w2() + "  score=" + b.score()));

For n-grams longer than two, tokenize sentences first, then call NGram.apriori(sentences, maxN, minFreq). Index result[n] holds the n-grams (sorted by descending count). Scala / Kotlin ngram helpers accept raw text and handle sentence splitting and stemming internally.

{% include "components/playground-extra-actions.njk" %} 
import java.util.List;
import smile.nlp.NGram;
import smile.nlp.tokenizer.*;

String[] docs = {
    "Machine learning is part of artificial intelligence.",
    "Deep learning is a type of machine learning."
};
var splitter = SimpleSentenceSplitter.getInstance();
var tokenizer = new SimpleTokenizer();
List<String[]> sentences = java.util.Arrays.stream(docs)
    .flatMap(d -> java.util.Arrays.stream(splitter.split(d)))
    .map(tokenizer::split)
    .toList();

NGram[][] result = NGram.apriori(sentences, 3, 2);
for (NGram g : result[2]) {
    System.out.println(String.join(" ", g.words()) + "  count=" + g.count());
}

Keywords

String body = "Machine learning is a field of artificial intelligence. "

    System.out.println(String.join(" ", k.words()) + "  count=" + k.count()));

Relevance Ranking

Plug a RelevanceRanker into Corpus.search to rank documents for a query string or token array. TFIDF is classic weighted bag-of-words; BM25 is Okapi BM25 for ad-hoc retrieval.

TF-IDFTFIDFClassic weighted bag-of-words

Taxonomy

A Taxonomy is an ordered IS-A tree of Concept nodes. Each concept carries a synonym set via keywords() (not getKeywords()). TaxonomicDistance implements Wu–Palmer-style measures; call dist.d("dog", "cat") for pairwise distance.

Java {% include "components/playground-extra-actions.njk" %} 
import smile.nlp.taxonomy.*;

Taxonomy taxonomy = new Taxonomy("entity");
Concept entity = taxonomy.getConcept("entity");
Concept animal = entity.addChild("animal");
Concept plant = entity.addChild("plant");
Concept dog = animal.addChild("dog");
Concept cat = animal.addChild("cat");
plant.addChild("rose");

Concept c = taxonomy.getConcept("dog");
System.out.println(c.keywords());

TaxonomicDistance dist = new TaxonomicDistance(taxonomy);
System.out.println(dist.d("dog", "cat"));
System.out.println(dist.d("dog", "rose"));
