Regression

The smile.regression package is a complete suite of supervised regressors for predicting a continuous response. Every algorithm exposes static fit(…) factories, implements Regression<T>, and is serializable.

This page covers the core abstractions (including nested Options / Properties), synthetic 1-D / 2-D helpers plus Abalone, an algorithm selection guide, then each family with runnable Java / Scala / Kotlin playgrounds. Expected outputs cite unit-test metrics where available; plot demos open a Swing window.

Core Abstractions

Regression<T> extends ToDoubleFunction<T>: predict(x) returns a scalar, with batch overloads for arrays, lists, and datasets. Optional online learning uses update(x, y). Probe that capability with online() (not isOnline()) before calling update — the default implementation reports false for batch-only models.

Options and Properties

Most algorithms expose a nested Options record for strongly typed hyperparameters (for example RandomForest.Options, SVM.Options, OLS.Options). Construct an Options instance and pass it to fit, or load the same knobs from a configuration file via java.util.Properties. Each Options type supports toProperties() and Options.of(props) for round-trips. Property keys use underscores (e.g. smile.random_forest.trees); algorithm sections below list the field name and the corresponding full property key in a description list.

{% include "components/playground-extra-actions.njk" %} 
import java.util.Properties
import smile.regression.RandomForest
import smile.data.formula.Formula

// Strongly typed Options
var options = new RandomForest.Options(200)
RandomForest model = RandomForest.fit(formula, data, options)

// Or configuration-file style Properties
Properties params = new Properties()
params.setProperty("smile.random_forest.trees", "200")
params.setProperty("smile.random_forest.max_depth", "10")
model = RandomForest.fit(formula, data, params)

// Round-trip
Properties props = options.toProperties()
var again = RandomForest.Options.of(props)

Synthetic generators

generate1d(n) places x on [0, 1] with y = sin(2πx) + 0.1·noise. generate2d(n) samples x on [-1, 1]² with y = x₀ − x₁² + 0.1·noise. Wrap arrays into a DataFrame with DataFrame.of + DoubleVector and Formula.lhs("y") for tree / OLS demos.

visualize1d

Two overloads: Regression<double[]> (scatter + dense LinePlot), and DataFrameRegression + training frame + x-column name (builds a grid DataFrame for the curve).

import smile.data.DataFrame;
import smile.math.MathEx;
import smile.plot.swing.*;
import smile.regression.DataFrameRegression;
import smile.regression.Regression;

/** Scatter of training points + line of dense predictions (array model). */
Figure visualize1d(Regression<double[]> model, double[][] x, double[] y) {
    int n = x.length;
    double[][] points = new double[n][2];
    for (int i = 0; i < n; i++) {
        points[i][0] = x[i][0];
        points[i][1] = y[i];
    }
    double lo = MathEx.colMin(x)[0], hi = MathEx.colMax(x)[0];
    int m = 100;
    double step = (hi - lo) / (m - 1);
    double[][] curve = new double[m][2];
    double[][] grid = new double[m][1];
    for (int i = 0; i < m; i++) {
        grid[i][0] = lo + i * step;
        curve[i][0] = grid[i][0];
        curve[i][1] = model.predict(grid[i]);
    }
    var figure = ScatterPlot.of(points, 'o').figure();
    figure.add(LinePlot.of(curve));
    return figure;
}

compare1d

Overlay a dashed OLS baseline with several solid curves for different hyperparameter settings on the same scatter (same generate1d / response1d sinusoid as OLS). Pass parallel models and labels arrays; LinePlot legends map each colour to its hyperparameter (via Palette.get(k)). Dual overloads match visualize1d (Formula vs array models).

{% include "components/playground-extra-actions.njk" %} 
import java.awt.Color;
import smile.data.DataFrame;
import smile.math.MathEx;
import smile.plot.swing.*;
import smile.regression.DataFrameRegression;
import smile.regression.Regression;

/** Scatter + dashed OLS + solid curves for several hyperparameter settings. */
Figure compare1d(DataFrameRegression ols, DataFrameRegression[] models, String[] labels,
        DataFrame train, String xCol) {
    double[] xv = train.column(xCol).toDoubleArray();
    double[] yv = ols.formula().y(train).toDoubleArray();
    int n = xv.length;
    double[][] points = new double[n][2];
    for (int i = 0; i < n; i++) {
        points[i][0] = xv[i];
        points[i][1] = yv[i];
    }
    double lo = MathEx.min(xv), hi = MathEx.max(xv);
    int m = 100;
    double step = (hi - lo) / (m - 1);
    double[][] gridX = new double[m][1];
    for (int i = 0; i < m; i++) gridX[i][0] = lo + i * step;
    DataFrame grid = DataFrame.of(gridX, xCol);

    double[] olsPred = ols.predict(grid);
    double[][] olsCurve = new double[m][2];
    for (int i = 0; i < m; i++) {
        olsCurve[i][0] = gridX[i][0];
        olsCurve[i][1] = olsPred[i];
    }
    var figure = ScatterPlot.of(points, 'o').figure();
    figure.setLegendVisible(true);
    figure.add(LinePlot.of(olsCurve, Line.Style.DASH, Color.DARK_GRAY, "OLS"));
    for (int k = 0; k < models.length; k++) {
        double[] pred = models[k].predict(grid);
        double[][] curve = new double[m][2];
        for (int i = 0; i < m; i++) {
            curve[i][0] = gridX[i][0];
            curve[i][1] = pred[i];
        }
        figure.add(LinePlot.of(curve, Line.Style.SOLID, Palette.get(k), labels[k]));
    }
    return figure;
}

Longley LOOCV RMSE with λ = 0.1 is about 1.732 in the unit tests. On the shared 1-D sinusoid, several λ values are plotted with OLS via compare1d — stronger shrinkage pulls the line toward a constant.

Practical Tips

  • Probe online learning. Call online() (not isOnline()) before update.
  • Scale-sensitive models. Normalize for Ridge / LASSO / ElasticNet diagnostics fairness, SVR, RBF, GPR, and MLP. Trees are scale-invariant.
  • Formula vs arrays. Use Formula + DataFrame for mixed / categorical tabular data (trees, ensembles, OLS family); use double[][] for numeric matrices and kernel / neural methods.
  • Validation. Prefer CrossValidation.regression or LOOCV.regression with RMSE / R2; seed with MathEx.setSeed(…) for reproducible ensembles and folds.
  • Serialize. Write.object(model, path) / Read.object(path).
  • Properties configs. Prefer nested Options when coding; use the property keys listed under each algorithm (underscores, e.g. smile.random_forest.trees) for configuration files. Round-trip with toProperties() / Options.of(props).
  • Large n. Prefer tree ensembles; exact GPR and kernel SVR scale poorly — use approximations or linear SVR.
  • RLS. Keep OLS.Options.recursive enabled when you need streaming coefficient updates.
